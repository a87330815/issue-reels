이용약관 (Terms of Service)

최종 수정일: 2026-11-19

1. 서비스 개요

본 서비스("쫌봐봐", jjombwabwa)는 Instagram 및 TikTok에 뉴스 카드뉴스 콘텐츠를 자동으로 게시하는 개인 프로젝트입니다.

2. 이용 조건

본 서비스는 콘텐츠 게시 자동화 목적으로 Instagram Graph API 및 TikTok Content Posting API를 사용합니다. 사용자는 각 플랫폼의 이용약관을 준수해야 합니다.

3. 면책 조항

본 서비스에서 제공하는 콘텐츠는 정보 제공 목적이며, 정확성을 보장하지 않습니다. 콘텐츠 사용으로 인한 손해에 대해 책임지지 않습니다.

4. 지적재산권

본 서비스에서 생성된 콘텐츠의 저작권은 운영자에게 있습니다.

5. 약관 변경

본 약관은 사전 고지 없이 변경될 수 있으며, 변경 사항은 본 페이지에 게시됩니다.

6. 연락처

문의사항은 GitHub 이슈를 통해 연락해 주세요.
