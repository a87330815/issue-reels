# 쫌봐봐 카드뉴스 고정 기준본

템플릿 ID: `jjombwabwa-cardnews-7-v1`

이 폴더의 7장 이미지는 사용자가 최종 승인한 시각 기준본이다. 자동 생성 시 큰 틀과
페이지 역할은 바꾸지 않고 주제에 맞는 사진·제목·본문만 교체한다.

1. 표지: 핵심 제목, 주제 사진, 한 줄 소개
2. 배경/이유: 관련 기관·당사자·현장 사진
3. 첫 번째 영향
4. 두 번째 영향
5. 세 번째 영향
6. 핵심 정리와 향후 관전점
7. `쫌봐봐` 구독·좋아요 고정 마무리

필수 품질 기준:

- 1080×1350, 총 7장
- 사진 영역과 텍스트 영역을 명확히 분리
- 1~6장은 서로 다른 사진
- 사진은 해당 장의 문장과 직접 관련되어야 함
- 국내 경제·정치는 한국 기관·원화·서울 등 한국 맥락을 확인
- 외국 화폐, 가상화폐, 부동산, 생활꿀팁 사진으로 대체 금지
- 사진 적합성을 확인할 수 없으면 생성·게시 중단
- 7장은 이 폴더의 고정 마무리 디자인과 문구 유지
