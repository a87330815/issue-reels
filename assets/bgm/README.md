# BGM (배경음악)

이 폴더에 로열티프리 mp3/wav/m4a/ogg 파일을 넣으면
릴스 영상에 자동으로 배경음악이 깔립니다.

- 여러 파일이 있으면 랜덤으로 하나 선택
- TTS 나레이션 볼륨 대비 약 8%로 재생 (방해 안 됨)
- 페이드인 1초, 페이드아웃 2초 자동 적용
- `--no-bgm` 플래그로 비활성화 가능

## 현재 트랙

| 파일 | 장르 | 설명 |
|------|------|------|
| `lofi_chill_01.mp3` | Lo-fi Chill | 피아노 코드 + 소프트 드럼, 잔잔한 lo-fi |
| `ambient_news_02.mp3` | Ambient | 패드 사운드 + 미니멀 비트, 뉴스 배경 |
| `soft_electronic_03.mp3` | Soft Electronic | 아르페지오 + 클린 비트, 깔끔한 느낌 |

## 커스텀 BGM 추가

더 좋은 트랙으로 교체하려면 이 폴더에 mp3/wav 파일을 넣으세요.

### 추천 소스 (로열티프리)

- [Pixabay Music](https://pixabay.com/music/) — 무료, 저작권 표시 불필요
- [Uppbeat](https://uppbeat.io/) — 무료 플랜 제공
- [YouTube Audio Library](https://studio.youtube.com/channel/UC/music)

### 추천 검색 키워드

`lofi news background`, `ambient corporate`, `soft electronic`, `chill beat`
