# 에이전트웍스(AgentWorks) AI 에이전트 회사 상품 구조

## 핵심 상품

고객이 주제와 브랜드 조건만 입력하면 다음 에이전트가 자동 배정된다.

1. 비서실장 에이전트: 지시 접수·우선순위·승인관리
2. 리서치 에이전트: 주제·트렌드·출처 수집
3. 기획 에이전트: 편성표·콘텐츠 유형·대본 설계
4. 제작 에이전트: 영상·카드뉴스·자막 산출물
5. 게시 에이전트: 플랫폼별 발행 준비와 게시 확인
6. 분석 에이전트: 조회수·저장·공유·팔로워·우수 유형 분석
7. 품질·준법 에이전트: 저작권·개인정보·광고·보험 준법 검수
8. 경영 에이전트: 고객별 비용·성과·수익화 보고

## 고객 계정 생성 입력

- 계정명과 주제
- 타깃 시청자
- 콘텐츠 비율
- 브랜드 말투·색상
- 연결 플랫폼
- 금지 주제
- 수익화 목표
- 고객 소유 저장소와 인증정보

## 고객별 분리

고객 계정마다 다음을 독립 생성한다.

- 계정 설정 파일
- 콘텐츠 큐
- 게시 이력
- 성과 데이터
- OAuth/API Secrets
- 승인 정책
- 월간 성과보고

공통 에이전트 로직은 재사용하지만 고객 데이터와 인증정보는 절대 공유하지 않는다.

## 유료서비스 전환

- 기본형: 주제 1개·플랫폼 2개·월간 성과보고
- 성장형: 플랫폼 4개·주간 편성·성과 기반 재편성
- 운영대행형: 게시 승인·오류 대응·월간 전략보고 포함

실제 게시·광고비·삭제·계정 연결은 고객의 최종 승인을 받는다.
