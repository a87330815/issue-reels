# 비서실장 오케스트레이터

## 목표

대표의 한 번의 지시를 부서별 작업 카드로 분해하고, 독립 worker가 동시에 처리하도록 하는 회사 운영 핵심 모듈이다.

## 업무 흐름

1. 대표 지시 입력
2. 비서실장 분류·우선순위·승인 조건 생성
3. 부서별 큐에 작업 카드 배정
4. 부서 worker 병렬 실행
5. 결과·오류·재시도 상태 수집
6. 승인 필요사항만 대표에게 보고
7. 통합 성과보고와 운영허브 반영

## 부서

고객관리팀, 보험분석팀, 영업지원팀, 조직운영팀, 교육제작팀, 마케팅팀, 경영관리팀

## 사용 예시

```bash
python company/dispatch.py "쫌봐봐 오늘 콘텐츠 후보 3개 만들고 조회수·저장·공유 성과를 분석해"
```

게시·삭제·광고비·결제·계약·발송은 자동 실행하지 않고 승인 대기 상태로 남긴다.
