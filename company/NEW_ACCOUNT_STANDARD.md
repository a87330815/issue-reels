# 신규 콘텐츠 계정 확장 표준

## 목적

쫌봐봐와 굿리치 리치업지점에서 검증한 제작·게시·분석 구조를 다른 주제 계정에 반복 적용한다.

## 계정 추가 조건

1. 계정의 한 문장 목적
2. 대상 시청자
3. 콘텐츠 주제와 비율(합계 100)
4. 금지 주제와 준법 조건
5. 브랜드명·색상·말투
6. 연결 플랫폼과 계정 소유권
7. 수익화 방식

## 표준 파이프라인

주제 수집 → 신뢰성 검수 → 점수 평가 → 대본 → 영상/카드뉴스 → 플랫폼별 발행 → 게시 확인 → 조회·저장·공유·팔로워 분석 → 우수 유형 반영

## 복제 원칙

- 계정별 저장소와 인증정보를 분리한다.
- 한 플랫폼 오류가 다른 플랫폼을 중단시키지 않는다.
- 콘텐츠 원본 1개에서 플랫폼별 제목·길이·해시태그를 별도로 만든다.
- 실제 게시·삭제·광고비 집행은 대표 승인 기준을 따른다.
- 신규 계정은 최소 30개 게시물 또는 4주간 데이터를 모은 뒤 확대·중단을 판단한다.
- 쫌봐봐 기존 편성표와 주제 비율은 변경하지 않는다.

## 성과 판정

- 성장: 조회수 중앙값, 저장률, 공유율, 팔로워 순증이 함께 개선
- 반복: 우수 주제·형식을 다음 편성에 우선 배치
- 보류: 조회수만 높고 신뢰·브랜드 적합성이 낮은 형식
- 중단: 저작권·개인정보·준법 위험 또는 반복적인 저성과
