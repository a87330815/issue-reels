# 대표 지시 운영 방식

대표 지시는 한 줄로 접수한다.

예시:

- `쫌봐봐 이번 주 콘텐츠 5개 기획하고 조회수·저장·공유 성과 분석 준비`
- `리치업지점 보험정보 콘텐츠와 리쿠르팅 콘텐츠를 다음 주 편성표에 맞춰 준비`
- `두 계정의 지난 게시물 성과를 비교하고 저성과 형식 개선안 작성`

## 처리 흐름

1. GitHub Issue가 대표 지시 접수창 역할을 한다.
2. `대표 지시 자동 접수` workflow가 제목과 본문을 읽는다.
3. `dispatch.py`가 관련 부서를 자동 선정한다.
4. 부서 worker가 병렬로 결과를 만든다.
5. `executive_report.md`에 통합보고가 생성된다.
6. 게시·삭제·발송·광고비·계약은 승인 대기로 남는다.

## 현재 자동 산출물

- 계정별 콘텐츠 기획·검수·성과분석 항목
- 보험분석 체크리스트
- TA 대본·문자 초안
- 팀장 일정·리쿠르팅 후속 과제
- 교육·아침조회 구성안
- 경영 목표·매출·비용 보고 항목
